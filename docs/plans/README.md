# Plans (historical)

The documents in this folder are planning records written before or during
earlier work. They capture what was intended at the time and are not kept up to
date. Package names, file paths and requirements in them may no longer match
the code.

Do not treat a plan here as the description of current behaviour. Current
behaviour and rules live in:

- the package READMEs and guidance files (`packages/styles/`,
  `packages/react/`)
- [`docs/testing/`](../testing/README.md) and [`docs/theming/`](../theming/)
- the [constitution](../../.specify/memory/constitution.md)

New feature work is specified with Spec Kit under `specs/<n>-<slug>/`, which is
also a historical record once the feature ships. See the root
[AGENTS.md](../../AGENTS.md) for how the two relate.

Do not move, rename or delete the existing plans.
