# Grill me

<!-- Adapted from mattpocock/skills skills/productivity/grill-me/SKILL.md @ v1.3.1. MIT License, Copyright (c) 2026 Matt Pocock. -->

Run the `grilling` skill.

When grilling ends with a shared understanding of a delivery, tell the person
to run `/to-spec` to turn the conversation into a spec, and `/to-tickets`
afterwards if it needs more than one pull request. This skill files no issue
itself.

If the person does not want an issue, stop at the shared understanding.
