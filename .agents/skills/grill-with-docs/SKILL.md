# Grill with docs

<!-- Adapted from mattpocock/skills skills/engineering/grill-with-docs/SKILL.md @ v1.3.1. MIT License, Copyright (c) 2026 Matt Pocock. -->

Run the `grilling` and `domain-modeling` skills together: grill in rounds, and
as terms and decisions settle, follow `domain-modeling` to check them against
their owners and record them.

Terms land in `GLOSSARY.md`. Decisions land in the document that owns their
topic, as this repository's "Where current behaviour is documented" rule
requires. There is no ADR directory.
