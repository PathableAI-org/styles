Add `SrOnly`, the React counterpart of the `pathable-sr-only` utility. It renders a `<span class="pathable-sr-only">` for text that is hidden visually but read by screen readers, passes other attributes through and merges `className`. An optional `as` prop renders a `p` or an `h2` to `h6` heading instead, for example to name a region whose purpose is clear visually; focusable elements cannot be chosen.
