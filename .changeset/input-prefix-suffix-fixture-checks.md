Add the `pathable-input-group--error` and `pathable-input-group--success` state modifiers and the `pathable-input-group--2xs`, `--xs`, `--sm`, `--small`, `--md`, `--medium`, `--lg`, `--xl` and `--2xl` width modifiers to the input prefix/suffix group. Each width names the room left for the value: the group is capped at that width plus the input's padding beside the affix and its border, so the affix stays inside the group, unlike USWDS, which caps the whole group. A `pathable-icon` in a prefix or suffix is now 1.5rem square and centred, and a text prefix or suffix now has a box as tall as its text, so contrast checkers can measure it.
