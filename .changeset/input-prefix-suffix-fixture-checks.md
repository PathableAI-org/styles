Adds the `pathable-input-group--error` and `pathable-input-group--success` state
modifiers, and the `pathable-input-group--2xs`, `--xs`, `--sm`, `--small`,
`--md`, `--medium`, `--lg`, `--xl` and `--2xl` width modifiers, to the input
prefix and suffix group.

- Each width names the room left for the value: the group is capped at that
  width plus the input's padding beside the affix and its border, so the affix
  stays inside the group, unlike USWDS, which caps the whole group.
