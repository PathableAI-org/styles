**Breaking change**: the package now ships only the official surface: the static components that have a component page, the tokens and the utilities. Every class a component page or fixture names renders as before. `dist/styles.css` is about 29% smaller.

Removed:

- **JavaScript.** The `./js` (`dist/pathable.js`) and `./js/init` (`dist/pathable-init.js`) entry points and `src/js/`.
- **Components without a page.** The `.pathable-*` classes of accordion, activity list, app shell (and its layout and bottom navigation), banner, bento grid, card grid, character count, checklist, chip rail, cluster, combo box, container, content, dashboard header, date picker, date range picker, decorative background, display, embed container, empty state, file input, filter bar, filter pill, filterable option list, form row, form stack, graphic list, grid, header, heading, hero, icon button, icon tile, identifier, in-page navigation, inline, input mask, interaction states, KPI grid, language selector, layout docs, layout grid, loading, media block, modal, nav, optional form section, page error, range, record header, resource card, save status, schedule item, screenshot frame, section, segmented control, sidebar layout, site title, skeleton, skipnav, split, sticky panel, surface, text, text highlight, time picker, toast, tooltip, validation, wayfinder, wizard, wizard actions and workflow panel. Their `src/pathable-component-wrappers/` partials and the bundle partials (`pathable-communication`, `pathable-dashboard`, `pathable-discovery`, `pathable-form-controls`, `pathable-interaction-controls`, `pathable-layout`, `pathable-layout-composition`, `pathable-marketing-patterns`, `pathable-navigation`, `pathable-structured-workflow`, `pathable-typography`) are gone too.
- **Undocumented modifiers and elements of kept components.** `pathable-button--primary`, `--continue`, `--destructive`, `--save`, `--review` and `--low-emphasis`; `pathable-card--media`, `pathable-card--workflow` and its `__action`, `__meta` and `__status` elements; `pathable-table--sortable`, `--selected`, `--has-actions`, `--loading`, `--empty`, `--scrollable` and their `__cell--status`, `__cell-status-text`, `__row-actions` and `__empty-message` elements; `pathable-step-indicator__step`, `__step--complete`, `__step--completed`, `__step--current`, `__step-label`, `__segment--completed`, `__segment-count`, `__body` and `__body-text`, and `ol.pathable-step-indicator` as the root; and `.usa-current` as an alias of `.pathable-current` in pagination.
- **Custom properties.** Every `--usa-*` alias of a `--pathable-*` typography or utility token, and the undocumented component properties (`--pathable-button-*`, `--pathable-alert-*`, `--pathable-card-*`, `--pathable-form-max-width`, `--pathable-input-padding-*`, `--pathable-table-cell-padding-*`, `--pathable-tag-padding-*`, `--pathable-footer-padding-*` and the wizard, workflow panel, save status, decorative background, screenshot frame, bento and chip rail properties, with their `--usa-*` twins).
- **Images** that no remaining rule uses: `img/loader.svg` and `img/file*.svg`.

Migration: use the classes on the component pages in `components/index.md`. Replace `var(--usa-*)` with the `--pathable-*` name it aliased. Markup that relied on a removed class needs its own styles or a component with a page. `@pathableai/react` components built on removed classes (Accordion, ActivityList, AppShell, Banner, CardGrid, Cluster, ComboBox, Container, DashboardHeader, DatePicker, DateRangePicker, EmptyState, FilterableOptionList, FormStack, Header, Heading, IconButton, IconTile, Inline, Loading, MediaBlock, Modal, OptionalFormSection, PageError, Range, SegmentedControl, SidebarLayout, Skeleton, Skipnav, SplitLayout, Stack, Surface, Text, Toast) render without that CSS until React is updated; the Header's mobile menu no longer has its JavaScript.
