# SaveStatus

An inline indicator that shows whether the user's work is loading, saving,
saved, offline or failed to save, with a symbol or spinning ring and a fixed
text label. Put the class and one state modifier on an empty `<span>`. The
application swaps the state modifier as saving progresses; the class needs no
JavaScript of its own.

## When to use

- A form, wizard step or settings page saves automatically, and the user needs
  to see whether their changes are safe.

Use something else when:

- a page section is loading its content: use `pathable-loading`;
- a save failed and the user must act: show a `pathable-alert` that says what
  to do, as well as the error state here;
- the status must be in a language other than English: the labels are fixed
  in the stylesheet, so write your own text instead.

## Example

Load the stylesheet once in the application:

```css
@import '@pathableai/styles';
```

```html
<div role="status">
  <span
    class="pathable-save-status pathable-save-status--saved"
    aria-hidden="true"
  ></span>
  <span class="pathable-sr-only">All changes saved</span>
</div>
```

## Variants

Add exactly one state modifier to `pathable-save-status` and change it as the
state changes.

| Axis  | Value     | Class                           | What it is for                                    |
| ----- | --------- | ------------------------------- | ------------------------------------------------- |
| state | `plain`   | none                            | No indicator or label; only the element's content |
| state | `idle`    | `pathable-save-status--idle`    | Nothing to report; the element is hidden          |
| state | `loading` | `pathable-save-status--loading` | Saved work is being loaded; spinning ring         |
| state | `saving`  | `pathable-save-status--saving`  | A save is in progress; spinning ring              |
| state | `saved`   | `pathable-save-status--saved`   | The last save succeeded; ✓                        |
| state | `offline` | `pathable-save-status--offline` | No connection; changes are not being saved; ⚠     |
| state | `error`   | `pathable-save-status--error`   | The last save failed; ✗                           |

## Tokens

| What                  | Token                              |
| --------------------- | ---------------------------------- |
| Text size             | `--pathable-save-status-font-size` |
| Ring size             | `--pathable-save-status-icon-size` |
| Weight of the ✓ and ✗ | `--pathable-font-weight-bold`      |

Set the two size properties on the element or a container to resize it. The
ring size defaults to `1em`, the current text size. The state colours, the
ring colours and the 0.25rem gap are fixed values in the stylesheet, so a
theme does not change them.

## Composition

- Leave the element empty. The symbol and the label are generated by the
  stylesheet; text you put inside appears between them, so a state element
  with its own text shows two labels.
- Put it beside the form's title or its actions, in a row or on its own line.
  It adds no margin around itself.
- The element has no element classes.
- In forced colours mode the browser draws the ring's border in one system
  colour, so its turning cannot be seen; the label still changes.

## Guarantees

The guarantees are the list in the front matter at the top of this page. Each
is expected behaviour. One marked `status: unmet` is behaviour the component
does not have yet: do not rely on it. One marked `status: unverified` was read
from the package source and no test checks it yet.

With no override, the text is set at the theme's small type size, 1rem
(16 px at a 16 px root), whatever the size of the text around it. Set
`--pathable-save-status-font-size` to use another size.

The contrast is unmet. Today the symbol and the label are `#1cae96` for saved,
`#f5a623` for offline and `#dc3545` for error. On white they are 2.78:1, 2.03:1
and 4.53:1; on the theme's background colour, Shilling Silver (`#dde2e8`),
which an application may use as its page background, they are 2.14:1, 1.56:1
and 3.48:1. The stylesheet does not paint the page itself. Placing the
indicator on white does not make the saved and offline labels readable: until
this is met, show the state in visible text of your own, in a colour that meets
4.5:1 against its background, in place of the `pathable-sr-only` text.

## The consumer owns

- Accessibility. Put the indicator in a `role="status"` element that is on the
  page before the state first changes. Generated labels are not announced
  reliably when they change, so hide the indicator with `aria-hidden="true"`
  and put the same state, in words, in a `pathable-sr-only` element beside it.
- Changing the state modifier as saving starts, finishes, fails or goes
  offline, and telling the user how to recover from an error.
- Never relying on colour or symbol alone: the label carries the state.
- Layout around the indicator.
